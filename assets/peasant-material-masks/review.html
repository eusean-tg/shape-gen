Reusable masks

The region assignments live on the Blender faces and in a UV-space ID image. The thin belt uses a mask within faces, so the mesh did not need extra cuts. These masks can be reused for future palette or texture changes. The material labels were authored for this character; this is not automatic segmentation for arbitrary meshes.
